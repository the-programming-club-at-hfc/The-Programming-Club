# Security

Please don't report security problems in public issues or pull requests.

Report them privately through GitHub: the repo's **Security** tab → **Report a vulnerability**. Include what you found, how to reproduce it, and what someone could do with it. An officer will reply within a week.

In scope: this repo and the live site at programmingclub.dev. Never access or change other people's data while testing; use your own local setup (see [CONTRIBUTING.md](CONTRIBUTING.md)).
