# The Golden Keycap

The Hello, World Cup trophy. A giant keycap engraved with the club's rounded `>_` terminal-prompt logo, spray-painted gold, sits on a giant mechanical-keyboard switch, which sits on a black plinth with the club plaque. Winners sign the keycap.

## Printing on the P1S

To lay out your own plates, open **`trophy-parts.3mf`** in Bambu Studio. Every part is its own object (base, switch, keycap, and the plaque with its text already set to white filament), set up for the P1S but not sliced. Drag each one onto whichever plate you want.

Or open **`golden-keycap-p1s.3mf`** in Bambu Studio. It's already sliced for the P1S: the base, switch, and keycap on one plate in black PLA, 0.20 mm Standard, 15% infill, no supports, on a Textured PEI Plate. Bambu estimates **5 h 7 min and 309 g**. To build it by hand instead, import `stl/plate.stl` without auto-arranging; the layout is clear of the P1S's front-left exclusion zone.

To reprint just the switch, open **`switch-p1s.3mf`** (about 1 hour, 51 g).

The plaque prints separately: load `stl/plaque_plate.stl` and `stl/plaque_text.stl` together as one object with multiple parts, then give the text part white filament (or add a filament change at the first layer above 2.4 mm).

| Part   | File                                           | Size (mm)      | PLA    |
| ------ | ---------------------------------------------- | -------------- | ------ |
| Keycap | `stl/keycap.stl`                               | 90 × 90 × 47   | ~77 g  |
| Switch | `stl/switch.stl`                               | 78 × 78 × 60   | ~54 g  |
| Base   | `stl/base.stl`                                 | 150 × 124 × 62 | ~183 g |
| Plaque | `stl/plaque_plate.stl` + `stl/plaque_text.stl` | 118 × 40 × 3.2 | ~10 g  |

The single-part files are there for reprinting one piece.

## Finishing and assembly

1. Spray-paint the keycap gold. Mask the engraved `>_` first if you want it to stay black, or fill it with a black paint pen afterwards.
2. Glue the plaque into the pocket on the front of the base. Use CA glue or double-sided tape.
3. Drop the switch onto the round peg on top of the base. Its socket is off-centre: turn it so the socket side faces the plaque, and the switch sits centred on the top.
4. Press the keycap onto the cross-shaped stem.

Each joint has 0.25 mm of clearance per side. Add a drop of glue if one feels loose. The finished trophy is about 140 mm tall. Winners sign the keycap with a paint pen.

## Editing

Every part is generated by `build.py` in Blender, using the site's pixel font (Jersey 15). To change the plaque text, edit `PLAQUE_LINES` near the top of `build.py`, then rebuild the STLs and the sliced project:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P trophy/build.py            # STLs
/Applications/Blender.app/Contents/MacOS/Blender -b -P trophy/build.py -- render  # STLs + previews (~4 min)
python3 trophy/make_3mf.py                                                         # golden-keycap-p1s.3mf
python3 trophy/make_3mf.py switch                                                  # switch-p1s.3mf
python3 trophy/make_3mf.py parts                                                   # trophy-parts.3mf
```

`make_3mf.py` packs the STLs into a Bambu project and slices it (except `parts`) with Bambu Studio's own CLI and P1S presets. It needs Bambu Studio 2.8 or newer; the 2.4 CLI crashes. By default it uses a copy at `~/.local/share/bambu-cli/BambuStudio.app`, or pass the path to another `BambuStudio.app`.

The build script checks that every part is watertight before exporting it. The fonts in `fonts/` are under the SIL Open Font License.
